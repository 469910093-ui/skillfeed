SkillFeeder API

登录、发布自己的 skill、与官方发现流混排。仍然只推荐到 GitHub，不代装。

发布 Skill（UGC）登录后只交 GitHub 链接、标题、文案；不贴 SKILL.md 正文 GET /api/feedUGC + 官方索引混排；发现流全量免费 GET /auth/me当前登录用户 OpenAPI 文档交互式接口说明 静态发现站GitHub Pages 定时刷新的信息流

本地启动：python skillfeed.py api · 健康检查 /health
