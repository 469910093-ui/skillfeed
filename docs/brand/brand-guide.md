## 配色说明

- **品牌渐变**：紫 `#9860e7` → 青 `#49aaeb` → 薄荷 `#64e2d4`，IP 插画和 UI 字标同源
- **强调色**：深青绿 `#0d7377`（UI 交互专用，不当 IP 色）

## 风格铁律

1. **瘫团子**：瘫成一滩的 blob，底部融化状，禁止尖脑袋、禁止角、禁止硬边
2. **丧丧感**：圆小黑豆眼 + 小嘴弧线，圆眼睛呆萌，是"被喂了但懒得动"
3. **品牌原色**：紫#9860e7 → 青#49aaeb → 薄荷#64e2d4，不淡不灰
4. **扁平轻插画**：有柔和渐变但不做强烈 3D 实体
5. **腮红必在**：两团淡粉红，左右对称
6. **小手小脚**：小圆点，不画手指关节
