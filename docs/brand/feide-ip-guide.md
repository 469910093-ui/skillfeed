# 肥嘚（Féidé）IP 设计语言规范

> 本文件是肥嘚的**唯一造型真相源**。后续任何插画、UI 空态、引导页、周边物料中的肥嘚，都必须以此为准。
> 改造型前先改本文件，再产出新资产。

## 1. 角色设定

- **名字**：肥嘚（Féidé）
- **人设**：全世界最软的蛋蛋
- **物种**：一颗瘫成一滩的团子 blob，没有骨骼没有尖脑袋
- **性格**：呆萌的满足、慵懒、被喂了就不想动；有点生无可恋但又快乐
- **角色关系**：它就是用户本人——瘫着，技术资讯自动喂到嘴边
- **核心动作**：圆小黑豆眼呆萌地等着，卡片飘过来

## 2. 造型规范（硬约束）

### 2.1 整体轮廓

- **形状**：瘫成一滩的团子 blob，底部融化状，**没有尖脑袋**，底部微微摊开
- **比例**：宽 > 高，整体偏扁，像瘫着的蛋
- **无锐角**：所有轮廓线全圆角
- **材质**：扁平轻插画风格，有柔和渐变但不做强烈 3D 实体

### 2.2 配色（浅色板）

- **身体渐变**：水平方向，从左到右三段浅色：
  - 左端：淡薰衣草紫 `#c4b5fd`
  - 中间：淡天蓝 `#93c5fd`
  - 右端：淡薄荷 `#a7f3d0`
- **渐变方向永远水平**
- **腮红**：两团淡粉红，左右对称
- **眼睛**：深灰紫黑色，圆小黑豆眼，短粗线条形
- **嘴**：嘴角微微下撇，呆萌的

### 2.3 表情系统

| 表情 | 眼睛 | 嘴 | 使用场景 |
|---|---|---|---|
| **呆萌等喂**（主形象） | 圆小黑豆眼 | 小嘴弧线 | App 图标、主 Logo |
| **满足** | 弯月闭眼 | 微笑小弧线 | 完成态、空态 |
| **惊喜** | 大圆眼 + 高光 | 小 O 型嘴 | 新动态、发现新内容 |
| **睡觉** | 闭眼 | 小抿嘴 + Zzz | 加载、无内容 |
| **叹气** | 圆小黑豆眼 | 嘴角下撇 + 小云朵 | 空搜索、无结果 |
| **点赞** | 眯眼 | 开心 + 小爱心 | 收藏成功 |

### 2.4 四肢

- **手**：两团小圆点，从身体两侧探出
- **脚**：两团更小的圆点，底部微摊
- **不画关节、不画指甲、不画衣服**

## 4. 使用禁忌

| 禁止 | 原因 |
|---|---|
| 尖脑袋/角/硬边/椭球蛋形 | 违背"最软的蛋蛋"人设 |
| 浓烈饱和色（`#9860e7` 等深色） | IP 插画用浅色板，深色只给 UI |
| 大圆眼睛/写实眼睛 | 圆小黑豆眼是识别特征 |
| 大笑/夸张表情 | 呆萌满足才是灵魂 |
| 站着/有骨架感 | 永远瘫着 |
| 加衣服/帽子/道具 | 保持蛋蛋纯粹性 |
| 垂直渐变或跨色相扇推 | 品牌合规 |
