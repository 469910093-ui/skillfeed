# 肥嘚（Féidé）IP 设计语言规范

> 本文件是肥嘚的**唯一造型真相源**。后续任何插画、UI 空态、引导页、周边物料中的肥嘚，都必须以此为准。
> 改造型前先改本文件，再产出新资产。

## 1. 角色设定

- **名字**：肥嘚（Féidé）
- **物种**：一团松弛的信息泥/Blob，没有骨骼
- **性格**：慵懒、满足、被喂饱就不想动；发现好东西会惊喜但懒得起来
- **角色关系**：它就是用户本人——瘫在沙发上，Feed 自动把有用的技术资讯喂到嘴边
- **核心动作**：张嘴等喂饭（终端提示符/卡片飘进嘴里）

## 2. 造型规范（硬约束）

### 2.1 整体轮廓

- **形状**：圆滚滚的 blob，底部摊成一滩（像融化的果冻），上圆下塌
- **比例**：宽度大于高度，整体偏扁，体现"瘫"
- **无锐角**：所有轮廓线全圆角，没有任何硬边
- **材质**：软萌黏土/3D 哑光质感，表面微有光泽，像 Q 弹的年糕

### 2.2 配色（硬绑定品牌令牌）

- **身体渐变**：水平方向，从左到右三段：
  - 左端紫色 `#9860e7`
  - 中间青色 `#49aaeb`
  - 右端薄荷色 `#64e2d4`
- **渐变方向永远是水平**，不做垂直渐变、不做跨色相扇推
- **腮红**：两团粉红 `#f4a6c0` 左右对称，位置在眼睛下方
- **眼睛**：深紫黑色 `#2d1b4e`，短粗线条形（不是圆形眼睛）
- **嘴**：粉红 `#f0889e` 内嘴腔，张嘴时可见一颗小白牙

### 2.3 表情系统

| 表情 | 眼睛 | 嘴 | 使用场景 |
|---|---|---|---|
| **等喂**（主形象） | 半眯黑线眼 | 张嘴等饭，终端飘入 | App 图标、Logo、引导页首图 |
| **满足** | 弯月闭眼微笑 | 微笑小弧线 | 收藏成功、操作完成、空态 |
| **惊喜** | 大圆眼 + 高光 | 张嘴 O 型 | 发现新内容、有更新、新动态 |
| **睡觉** | 闭眼 + Zzz | 小抿嘴 | 加载中、无内容、夜间模式 |
| **点赞** | 半眯眼 | 开心张嘴 | 点赞成功、推荐好内容 |

### 2.4 四肢

- **手**：两团小圆点，从身体两侧探出，不画手指
- **脚**：两团更小的圆点，底部摊开与身体融化在一起
- **不画关节、不画指甲、不画衣服**

## 3. 终端提示符元素

- **形状**：深色圆角方块 `#0c1020`，里面白色 `>` 箭头 + 薄荷色 `#64e2d4` 下划线光标
- **发光**：方块边缘带极淡薄荷色光晕
- **角色**：代表一条被喂进肥嘚嘴里的命令/信息
- **用法**：只在"等喂"主形象中出现，不单独做独立图标

## 4. 使用禁忌

| 禁止 | 原因 |
|---|---|
| 垂直渐变或跨色相扇推（紫→粉→橙） | 撞 Instagram 禁用区，品牌合规 |
| 圆形眼睛或写实眼睛 | 破坏简约感，黑线眼是识别特征 |
| 加衣服、帽子、道具（耳机/眼镜除外后期评估） | 保持 blob 纯粹性 |
| 硬边/锐角轮廓 | 违背软萌黏土质感 |
| 粉/橙/红大面积身体 | 品牌身体色只有紫→青→薄荷 |
| 改变腮红颜色或去掉腮红 | 腮红是识别特征 |
| 肥嘚站着或有骨架感 | 永远瘫着，瘫是灵魂 |

## 5. 与品牌色板的关系

肥嘚身体色 = 品牌 `--brand-purple` → `--brand-cyan` → `--brand-mint` 渐变。
UI 强调色仍是 `--accent: #0d7377`（深青绿），不与肥嘚身体色混淆。
肥嘚是装饰/情绪载体，不当按钮色或交互色。
