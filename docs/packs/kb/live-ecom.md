# 知识库

按这个顺序做：选品上架 → 话术 → 开播 → 场控复盘。货盘没算过利润，先不要开播。

## 选品上架

先看货盘。用热销榜看什么在卖，优先轻小件。每个品都算一遍：售价减去商品成本、运费、平台佣金、营销成本。毛利率不到 30% 不上。

上架前写好一条完整商品详情：标题、卖点、本地化描述、关键词。标题埋词，主图前 3 秒写清卖点，详情按站点语言写。

每天找 5 个热卖商品，拆主图和评论区，放进选品表。选品表定了再写话术。

## 话术

货盘定了，再写话术。直播要先准备三块：场控话术、把人引进直播间的方法、转化节点上怎么接话。

nuwa-skill 拆对标主播：看他们怎么开场、怎么讲货、评论区在问什么。拆完的句子写进自己的话术，不要开播时现编。

## 开播

话术熟了再开播。开场用前三秒把人留住。dbs-hook 改这三秒：先给一个让人停下来的点，再进货品。这个点和选品卖点是同一句。

每天拆 5 个低粉高销视频，单独记下前 3 秒钩子和标题，存进抄作业表，下一场用。

## 场控复盘

这场结束再复盘。看播放、点击、出单这条漏斗。找出低播放、低转化的视频和商品，改完再发。

每周留一份店铺周报。把上品、测视频、处理差评、发货写成自己的操作步骤。下一场从选品表和话术改起，不要从零开播。
