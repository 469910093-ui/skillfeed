# 知识库

按这个顺序做：调研 → 拆对标 → 前三秒 → 内容 → 飞书案例库。案例库放在内容做完之后，用来接下一条，不要一开始就建空表。

## 调研

agent-reach 规划调研路线，收集内容和评论区痛点。

web-access 顺着这条路线自动找素材、看数据。素材先落下来，再决定拆谁。

当天热点先收成一份简报。Horizon 看重点，BettaFish 从公开热点里筛能带货的题。账号今天发这个、明天发那个，用 content-strategy 先定内容支柱和选题优先级，再从支柱里挑这一条。

## 拆对标

素材够了，用 nuwa-skill 拆带货达人和对标账号。看他们怎么开场、怎么讲货、评论区在问什么。

只有一个账号链接时，用 blogger-distiller。把链接或账号信息给它，看定位、选题方向和爆款怎么说。起号前先做这一步。

要对照很多条笔记，用 Spider_XHS。比标题、开场和结构，学的是结构，句子用自己的。评论区在问什么，用 MediaCrawler 把公开笔记和评论收回来，标出反复出现的需求。这些需求写进下一条的钩子。

做 TK 带货视频，可以不先学剪辑。拿一条对标视频，用技能把它逐段拆开，变成能照着做的生产资料。拆完再写自己的前三秒，不要倒过来。

## 前三秒

对标拆完，用 dbs-hook 写视频前三秒。第一下要让人知道这条片在讲什么、为什么继续看。钩子用调研里的痛点，不要另起一个话题。

## 内容

钩子定了，再写完整条。按这个顺序写，不要跳步。

1. 标题和开头像说明书，先用 dbskill 改钩子、标题和商业表达。它也用来拆别人的爆款是怎么起头的。
2. 有主题但展不开，用 Viral_Writer_Skill。给主题，它出初稿、几条备选标题和配图提示。初稿用你自己的经历补细节，不要原样发出去。
3. 这条要落在账号栏目里，用 xiaohongshu-ops-skill。它看账号、出选题、写正文，这条发完再复盘。框架用它，句子用你自己的。
4. 文案和配图要一起出，用 Auto-Redbook-Skills。它写笔记文案、配上图，也可以接着发布。
5. 这条要念出来，用 short-form-video-script。把书面稿改成口播：开场、节奏、目标时长。口播的第一句用上一节已经定下的钩子。

发出去之前去掉机器味。humanizer 拿掉「不仅如此」「总而言之」这类套话。中文腔重的用 humanizer-zh，专门看空话、套话、三段式、过度排比和机器腔。

小橡皮放在三个点上。用旧笔记看语气是不是模板；初稿写完，改掉生硬句和机械转折；发布前再看有没有容易误解或有风险的说法。它给的是改法，事实和最终语气你自己定。

dbs-ai-check 逐段标出像机器写的地方。先检测，再改，再检测一遍。改完再投。

按拆出来的生产资料复刻一条带货视频。不会剪辑，也可以先复刻这一条，再改成自己的品。口播素材用 claude-code-auto-video-edit 剪口播画面，剪的是已经写好的那版口播。不做传统剪辑时，用 Hyperframes 把文案收成一条片。同一条还要图和声音，用 Generative-Media-Skills，图、视频、声音跟的是同一句卖点。直播回放和访谈要改成笔记，用 video-to-subtitle-summary-skill 先转成字幕、摘要和结构化文案，再交给写稿那一步。

做完要发出去，用 social-auto-upload 发到多个平台。下一轮写什么，用 social-media-analyzer 比互动、点击和投入。收藏高的选题回到调研，点击高但收藏低的，回到钩子和标题。

## 飞书案例库

这条内容做完，再收进案例库，供下一次调研调用。

lark-shared 先打通飞书授权和权限。lark-base 再把素材、对标拆解和成片写进案例库。

账号要持续更新。social-ai-team 管定位、标题、内容日历和复盘，按日历发下一条。

一条流程跑顺了，用 skill-creator 收成固定技能。下次从调研直接调用，不要每条重新讲一遍。
