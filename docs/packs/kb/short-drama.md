# 知识库

按这个顺序做：选题 → 分镜 → 前三秒 → 成片。先看对标片在讲什么，再写自己的镜头表，最后才出片。

## 选题

nuwa-skill 拆对标账号和结构。看别人的片头怎么留人、故事从哪一拍开始、评论区在追问什么。

拆的时候记下前三秒钩子和结构。选题从这些钩子里定，不要只收藏成片。

## 分镜

选题定了，再抽分镜。从高赞脚本里只留题材和分镜：这一拍是谁、在做什么、观众为什么往下看。写成自己这一条的镜头表。镜头表没出来，不要开拍。

带货要用短剧讲法时，产品写进已经定好的某一拍里，讲的仍是这条片子的情节。不要另起一个只念卖点的广告脚本。

## 前三秒

分镜定了，再做片头。dbs-hook 改视频前三秒：第一下就要让人知道这条片在讲什么、为什么继续看。钩子用选题里记下的那一拍，和镜头表第一镜是同一件事，不要换一个新话题。

## 成片

片头能留人，再用 Pexo Skills 做成一条短剧。给它题材和上面那张镜头表，出成片。成片的前三秒要和镜头表一致。不一致就改镜头表或改片头，不要在成片上再换一个故事。
