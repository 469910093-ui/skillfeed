# 知识库

按这个顺序做：选题 → 长文 → SEO/GEO → 内容日历。先有选题和正文，再改到能被搜到，最后排进日历。

## 选题

Agent-Reach 做内容收集、评论区痛点和竞品账号研究。不知道下一篇写什么时，先从痛点里定题。题目定了再写长文。

## 长文

题目定了，用 ai-marketing-claude 把竞品、文案和结构串成一篇。单篇按这个顺序写完，再交给搜索优化。

资料和提纲还没接上，用 content-research-writer。它从查资料、搭提纲、补引用写到初稿，适合公众号、通讯和博客。引用没补上就不要定稿。

只能围着自己已经收集的资料写，用 NotebookLM Claude Code Skill。深度文章、行业研究和课程稿都围着资料库，不另外编事实。

公众号从选题做到排版，用 WeChat-Official-Account-content-studio。热点抓取、选题、写作、排版接成一条，适合按天更新。排版用的是这篇正文，不要排一篇、发另一篇。

篇幅要拉到长文，用 khazix-skills。它走的是长文和万字研究：热点分析、长文拆解、再写成自己的观点。短笔记的结构撑不起这一步。

先要一版能改的稿，用 Viral_Writer_Skill。给主题，它出初稿和标题。这版交给上面的长文流程改，不直接当定稿。

栏目不稳时，用 content-strategy 先定账号定位、内容支柱和选题计划，再排进后面的日历。没有栏目，日历只是一串互不相关的题目。

## SEO/GEO

正文写完，再用 claude-seo 改结构和措辞，让官网、公众号、博客和长笔记能被搜到，也覆盖 AI 搜索。写了很多但没人搜到时，回到这一步，不要先改日历。

做独立站时，搜索排名、AI 回答里被引用、本地获客，放在同一套技能里一起做。Shopify 站点也能用。先把这三件事配齐，再一篇篇改页面。

独立站可以把 Codex、GEO 和 SEO 放在一起用。页面既要能被搜到，也要能被 AI 回答引用到。已经有站的，长文改完就走这一步。

## 内容日历

这篇能被搜到了，再排下一篇。social-ai-team 管账号定位、标题、内容日历和复盘。按日历回到选题，不要写完一篇就断。
