# 知识库

按这个顺序做：定位地基 → 文案 → 广告 → SEO/AEO → 落地页转化。地基没写完，不要先做广告。

## 定位地基

先写一份地基：产品是什么、用户是谁、定位是什么。product-marketing 就是这份文档。后面的文案、广告、搜索、落地页都读它，不要每次重新交代。

Agent-Reach 用来把地基填实：内容收集、评论区痛点、竞品账号。痛点写进地基，再往下写文案。

## 文案

地基定了，再写字。Copywriting 按文案框架写。标题、正文和行动号召要一起出，用 Content Creation。说「给这个产品写首页文案」时，走文案模块，不要顺手改定价或改埋点。

邮件接在文案后面。Email Sequence 先读地基，再按序列一封封写。每一封都贴着真实产品，不要凭印象编卖点。

## 广告

文案能用了，再做广告。Ad Creative 只做广告创意，和文案模块分开，避免写成同一段话。

封面和海报用 GPT-Image2-Skill：小红书封面、品牌视觉、海报、图文配图。画面上的句子用上一节的文案。封面和配图不统一时，先回到地基里的定位，再出图。

## SEO/AEO

广告和内容都有了，再让它被搜到。claude-seo 管官网、公众号、博客、长笔记，以及 AI 搜索。

独立站要出现在别人的回答里，按这四步做，做完一步再做下一步。

1. 先问清楚：哪些帖子会被引用，引用的是真实体验、避坑，还是对比；你的品牌有没有出现在这些来源里。这一步只记帖子的共同点。广告文案留到文案那一节再写。
2. 选和产品相关的讨论区。把产品说明改成「我用下来是这样」的口吻，写进已经有人讨论的话题里。
3. 用具体场景去答：谁适合、什么情况下会出问题、和别的选法比怎么样。同一件事实在不同帖子里说法要一致。
4. 每两周用核心问题再搜一次，看答案里有没有你的说法。没有，就改帖子里的事实和场景，不要先加广告预算。

SEO+AEO 把搜索和问答引擎优化放在一起做。这一步改的是已经写好的页面，不是另起一篇。

## 落地页转化

页面能被找到之后，再看成交。Page CRO 专管有流量但不成交：看落地页哪里让人离开，改完再测。改文案时回到文案模块，改画面时回到广告，不要在转化这一步重写全部。

## 持续做下去

一轮跑完，用 social-ai-team 管账号定位、标题、内容日历和复盘，按日历做下一轮。

ai-marketing-claude 把竞品、文案和内容日历收成市场部流程。也可以让一个总控来拆任务：你说要做一场营销活动，它把文案、广告、搜索、邮件、落地页分给对应技能。每个技能只管自己那一段。
