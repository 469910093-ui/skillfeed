# 知识库

按这个顺序做：市场 → 竞品 → 选品 → 价格和供应链 → Listing → 视觉 → 广告 → 净利润。不要一上来把工具装满。先跑通一条线，看清每一步用什么、用完接到哪里。

主线是：市场判断 → 产品机会 → 竞品价格 → 1688 拿货价 → 平台费用 → Listing → 广告测试 → 净利润复盘。

这条线顺了，再加：多平台同步、供应链优化、国际物流、一件代发、持续复盘。

## 市场

用 Codex 做跨境，先让它碰到真实经营数据，再问问题。品还能不能做、哪个关键词值得打、竞品流量从哪来、差评具体在骂什么，都靠数据回答。

SellerSprite 看市场、竞品、关键词和选品。它可以归并数据、写成结论。专利、认证、物流限制和真实利润仍要人工核对。

亚马逊上先用「亚马逊-前端商品搜索」看前端正在卖什么。

站点选品报告只输入三个词：平台、国家、类目。报告里要有市场规模、品类边界、趋势和季节性、价格带、做 / 观望 / 不做、90 天行动、流量和广告打法。

## 竞品

搜索有了候选，再拆页面和评论。

「亚马逊-前端商品详情」看标题、图片、五点描述、规格，拆竞品 Listing。

Amazon Reviews 按站点和星级筛评论，抽出高频痛点、好评卖点和情绪。「亚马逊-商品评论」用来挖差评原因和真实购买需求。这些句子后面要写进 Listing。

## 选品

市场和竞品都看过，再决定做不做。选品池怎么筛、类目值不值得进、竞品靠什么起量、关键词有没有机会、评论里有哪些改良点，逐项写下来。

亚马逊卖家要有一套随时能调用的自动化技能。每个技能管一段，再合到这条线上。成熟度看你能调用多少技能。报告可以继续看，调用得上的技能才算班底。

## 价格和供应链

选品定了，先算能不能赚钱，再写 Listing。

「亚马逊-店铺定价」看价格带和调价空间。拿货对着 1688 价格和平台费用算，利润站住了再往下做。

## Listing

价格带清楚了，再改页面。

「亚马逊-店铺目录」先看清店里有哪些商品、结构怎么分布。「亚马逊-店铺listing管理」整理商品内容，批量检查，再按竞品评论里的痛点改标题和五点。

判断仍要人来做：哪个品能做、哪个 Listing 该改。

## 视觉

Listing 结构定了，再补图和视频。LinkFox AI 做商品图处理、主图和场景图，并把静态商品图转成动态视频。视觉产量大的时候用它补产能。图上的卖点跟 Listing 五点一致。

## 广告

页面能看了再投。「亚马逊-广告管理」看广告组、投放数据、预算消耗，决定往哪优化。广告测试的结果回到净利润，不要单独看点击。

## 净利润和复盘

广告跑起来之后，看净利润，再决定下一轮改选品、改 Listing，还是停广告。

LinkFox Agent 把市场、竞品、店铺数据和运营报告串在一起。数据和报告太散时用它收口。

Self-Improving Agent 记下这次任务里的错误和有效做法，下次少解释一遍。同类任务反复返工时用它。

「亚马逊-最新政策资讯」提前看到规则变化，避免复盘时才发现页面违规。
