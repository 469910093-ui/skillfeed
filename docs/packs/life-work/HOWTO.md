# 生活工作提效 · 操作手册

装好以后先读这一页。后面换别的场景包，目录还是这八节。

## 1. 这个包帮你完成什么

让刚装上 AI 编辑器的人，用**说话 + 粘贴**，把会、聊天、草稿收成能发出去的待办和周报。  
今天不接飞书、不接日历、不装一排工具。

## 2. 今天先做哪一件

打开旁边的 `drills/01-meeting.txt`（或换成你自己的一段会议记录），在对话框里**整句复制**：

> 按操作手册练习 1：把这段纪要整理成待办，并写三句给领导的进展。数字只能来自材料。

十分钟内你应该看到：一份勾选清单 + 三句进展。没有这两样，先看第 8 节，不要换下一个练习。

## 3. 怎么对 Agent 说话

就这么说，不用记技能名：

- 「把这段纪要整理成待办，并写三句给领导的进展。」
- 「这段邮件去 AI 味，改成我能直接发出去的口吻。」
- 「根据 `待办/` 里这周的事，写一份一页周报。」
- 「把这份周报收成三页幻灯，只保留结论。」
- 「这个包装好了，下一步练哪个？」

不要说：「运行 skillpick」「打开 MCP」「选一个最强的模型」。

## 4. 材料放哪

在本机新建三个文件夹（名称不要改）：

```
纪要/     会议记录、聊天摘录，原文丢进来
待办/     Agent 整理后的清单，你改勾选
本周/     周报、幻灯，能拿出去的成品
```

有文件就拖进去再说「按文件夹里的材料做」。空口描述、又没有粘贴，Agent 容易编。

## 5. 每个 Part 何时用

| 你卡在 | 你就说 | 成功长什么样 |
|---|---|---|
| 不知道这个包怎么用 | 「按操作手册带我做练习 1」 | 开始改 `drills/01-meeting.txt`，而不是列菜单 |
| 句子像机器写的 | 「去 AI 味，我要能发出去」 | 像你平时说话，没有「赋能」「闭环」 |
| 会开完一堆事没人跟 | 「整理成待办 + 三句进展」 | 每条待办有人、有截止日期（材料里有才写） |
| 周五要交差 | 「根据待办写一页周报」 | `本周/` 里一份能转发的短文 |
| 要开会讲 | 「收成三页幻灯，只留结论」 | 不是把周报再贴一遍 |

一次只做一行。做完练习 1，再打开 `drills/02-email.txt`、`drills/03-weekly.txt`。

## 6. 不要做的事

- 让 Agent **自己编数字、编截止日期**。材料里没有就写「未知」。
- 第一天去接飞书、日历、浏览器一串账号。
- 让 Agent **替你选定**用哪个技能；你可以说人话，点头再改文件。
- 把整份合同、密码、身份证丢进对话框。

## 7. 第二天才能接的手

练习 1–3 都跑通之前，这一节跳过。

之后只开 **一个**：飞书（任务/文档）或系统日历。开通时对 Agent 说：

> 我要接飞书，只读任务和文档，先出计划不要写配置。

对方列出要改的配置、你点头，再继续。不要同一天开五个。

## 8. 坏了怎么办

**只回了一堆建议，没有待办**  
再说一遍：「按练习 1，直接给出待办清单和三句进展，不要解释。」仍没有，把 `drills/01-meeting.txt` 再贴一次。

**数字对不上 / 出现材料里没有的人**  
说：「删掉材料里没有的人名和数字，标出未知项。」

**它要改很多文件、你没点头**  
说：「先不要写盘，只把结果打在对话里。」点头后再让它写入 `待办/` 或 `本周/`。
